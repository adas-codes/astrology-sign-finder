# Astrology Sign Finder

A simple static website that lets a user enter a date of birth and compare their sign across:

- Western zodiac
- Vedic zodiac
- Pagan seasonal sign system

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server such as:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
