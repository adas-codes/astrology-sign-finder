# Astrology Zodiac Finder

A simple static web app that lets the user enter a date of birth in `DD/MM/YYYY` format and compare their sign across multiple zodiac systems.

## Included systems

1. Western Tropical Zodiac
2. Vedic Sidereal Zodiac (Jyotish)
3. True Sidereal / Astronomical Zodiac
4. Chinese Zodiac (Shengxiao)
5. BaZi (Four Pillars of Destiny)
6. Tibetan Zodiac
7. Mayan Zodiac
8. Aztec Zodiac
9. Native American Earth Astrology
10. Celtic Tree Zodiac
11. Ancient Egyptian Decan System
12. Burmese Zodiac (Mahabote)

## Features

- DD/MM/YYYY validation
- Responsive layout
- Results displayed in separate cards for each zodiac system
- No backend required

## Run locally

From the project folder, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files

- `index.html` – page structure
- `style.css` – styling and layout
- `script.js` – zodiac logic and date handling

## Note

This is a frontend astrology comparison app and uses simplified, interpretive date-range logic for many systems. It is intended for educational and entertainment purposes.
